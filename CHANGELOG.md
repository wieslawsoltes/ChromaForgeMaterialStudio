# Changelog

## 0.1.0 — September 15, 2026

Initial engineering-preview release of ChromaForge Material Studio. Includes the plain HTML/JavaScript editor, original NOMAD sample, procedural materials, editable texture/layer tools, mesh I/O and baking, three rendering paths, local project format, authenticated SQLite/WebSocket service, website and six standalone library packages.

Executed validation: 66 Node tests, 32 editor-browser checks, 13 website/SDK-browser checks, syntax/export checks and TypeScript declaration checks. All passed in their documented scope. GPU backends and browser IndexedDB persistence were not available for runtime validation in this environment; screenshots use the labeled software compatibility renderer. Full original-product parity, enterprise hardening, public deployment and registry publication are not established.

Read docs/FEATURES.md, docs/SECURITY.md and docs/QA.md before adopting this release.
